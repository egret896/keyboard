# KKKeyboard（仮称）

Galaxy Z Fold7 で使うための、自分用の日本語フリックキーボードです。
オープンソースの日本語キーボード [Zinna-IME](https://github.com/soichi11208/Zinna-IME) を土台にしています。

```
┌──────────────────────────────┐
│  候補バー（漢字の変換候補）              │
├────┬─────┬─────┬─────┬────┤
│ ↶  │  あ  │  か  │  さ  │ ⌫  │
│ ◀  │  た  │  な  │  は  │ ▶  │
│ ☺記 │  ま  │  や  │  ら  │ ␣  │
│あA1 │ ゛小゜│  わ  │  、  │ ↵  │
└────┴─────┴─────┴─────┴────┘
 ☺記 … 記号・絵文字・顔文字パネル（履歴／カテゴリのタブ付き）
 あA1 … かな → 英字 → 数字 の順に切り替え
```

- **プライベートモード**：候補バーの「🔓 プライベート」をタップでON（🔒）。ONの間は学習も履歴の保存もしません
- **定型文**：「☺記」→「定型文」から入力。登録は設定画面で（1行に1つ）
- **Fold を開いたとき**：左右に「あかさ…」を分けた両手入力の配置に自動で切り替え（設定でオフにできます）


## スマホへの入れ方

1. スマホのブラウザで、このページの右側（または下）にある **Releases → 最新版** を開く
2. **my-keyboard.apk** をタップしてダウンロード
3. ダウンロード完了の通知をタップ →「インストール」
   - 「この提供元のアプリは許可されていません」と出たら、**設定** を押して **「この提供元を許可」** をオンにして戻る
4. スマホの **設定 → 一般管理 → キーボード一覧と既定 → キーボード一覧** で **KKKeyboard** をオン
5. 文字入力欄を開き、右下のキーボードマーク（または「既定のキーボード」）で **KKKeyboard** を選ぶ

背景画像は、アプリ一覧の **KKKeyboard** を開いた設定画面から選べます。
